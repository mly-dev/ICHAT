# Assets

Icônes de remplacement, aplats aux couleurs de la marque, générées pour que le
build passe. **À remplacer par les exports Figma « E-CHAT » avant publication.**

| Fichier | Format attendu |
|---|---|
| `icon.png` | 1024×1024, sans transparence, sans coins arrondis (les stores les ajoutent) |
| `adaptive-icon.png` | 1024×1024, motif centré dans les 66 % centraux (Android rogne les bords) |
| `splash.png` | 1284×2778 ou logo centré sur fond `#0B5FFF` |
| `notification-icon.png` | 96×96, monochrome blanc sur fond transparent (exigence Android) |
| `favicon.png` | 48×48 |
